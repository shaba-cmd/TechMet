# ТехМЕТ — магазин парка техники

Адаптивный сайт компании по аренде спецтехники, свёрстанный по дизайн-макету (курсовая работа).

**Демо:** [ТехМЕТ — магазин парка техники](https://tech-met.vercel.app/)

**Стек:** React 19, TypeScript, Vite, Node.js, Express.

Возможности: каталог техники (34 позиции), поиск, фильтры по цене, категориям и производителям с сохранением в `localStorage`, вкладки разделов, сортировка, пагинация, карточка техники в модальном окне, форма заявки с валидацией, мобильное меню, блок FAQ.

## Запуск

```bash
npm install
npm run server    # сервер Express: http://localhost:3001 (API и база данных)
npm run dev       # сайт в режиме разработки: http://localhost:5173
npm run lint      # ESLint
```

`npm run server` и `npm run dev` запускаются в двух терминалах. Чтобы запустить всё одной командой,
используйте `npm start`: сайт собирается и открывается вместе с сервером на http://localhost:3001.

## Сервер и админ-панель

- **Стек:** Node.js + Express.
- **База данных** — файл `server/data/db.json`. Создаётся при первом запуске сервера из `src/data/products.json`.
  Посмотреть содержимое можно в редакторе или в браузере: http://localhost:3001/api/products.
- **Загруженные фотографии** сохраняются в `server/uploads/`.
- **Админ-панель:** http://localhost:3001/#/admin.
  Логин `admin`, пароль `igr2007`. Свои значения задаются переменными окружения `ADMIN_LOGIN` и `ADMIN_PASSWORD`.

| Метод | Адрес | Доступ | Действие |
|---|---|---|---|
| GET | `/api/products` | все | список карточек |
| POST | `/api/login` | все | вход, возвращает токен |
| POST | `/api/products` | администратор | добавить карточку |
| PUT | `/api/products/:id` | администратор | изменить карточку |
| DELETE | `/api/products/:id` | администратор | удалить карточку |
| POST | `/api/upload` | администратор | загрузить фотографию |

Если сервер недоступен (например, на статическом хостинге), сайт показывает исходный каталог из `src/data/products.json`.
